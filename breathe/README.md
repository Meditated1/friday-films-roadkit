# breathe, as you wish

A small, calm standalone breathing app. A dark zen pond fills with soft color as
you inhale and drains as you exhale, paired with a deep **Tide** tone. Pick the
pattern, the length, the look, and the sound — breathe however you wish.

This is **Gen 1**: one self-contained `index.html` (vanilla JS, Canvas, Web
Audio — no frameworks, no build step, no backend). The JS is written
module-shaped (`Store / Themes / Patterns / Reflections / Pond / Tide / Clock /
App`) so it can be split into files later.

## Run it

Open `index.html` in a browser, or serve the folder:

```sh
cd breathe && python3 -m http.server 8000   # → http://localhost:8000
```

Audio (Web Audio) is created on the first **始める · begin** tap, as iOS
requires. The Tide plays through the speaker and **follows the phone's hardware
silent switch** — this is noted in-app.

## Patterns

| Pattern | Breath |
|---|---|
| **Box** 四角 | 4-4-4-4, grounding |
| **4·7·8** 安眠 | in 4, hold 7, out 8 — for sleep |
| **Coherent** 調和 | even 5.5/5.5 (or 6/6) |
| **Calm** 静 | in 4, out 6 |
| **as you wish** 随意 | custom — set each count, toggle holds; persisted |

Length: 2 / 5 / 10 minutes or “until I stop.” Cycle counts are computed honestly.
Each session opens with a 10-second settle-in and closes with a quiet reflection.

Prefs (pattern, length, theme, sound, custom pattern) and a gentle session
count / streak persist in `localStorage` — no accounts.

## Add to home screen (PWA)

Includes a web manifest, `apple-touch-icon`, and the iOS meta tags
(`apple-mobile-web-app-capable`, status-bar style, title, `theme-color`,
`viewport-fit=cover`) so it launches full-screen with no Safari chrome.

Icons are generated by `make_icons.py` (pure stdlib — no Pillow):

```sh
python3 make_icons.py
```

## Deploy — Cloudflare Pages (private repo)

Cloudflare Pages serves from a **private** repo on the free tier (unlike GitHub
Pages, which needs a public repo). Point a Pages project at this repo with:

- **Build command:** _(none)_
- **Build output directory:** `breathe`

It's all static — nothing to build.
